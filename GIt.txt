1. Создаем репозиторий на гитхабе с создание Readme файла
2. копируем https из вкладки Code
3. в консоли гита: git clone https...
4. после добалвения файлов пишем gis status
5. потом пишем git add (имя каждого файла) для каждого файла
если нет лишних файлов пишем git add -a
6. если добавили что-то лишнее то командой git restore --staged <имя файла> убираем его
7. git commit -m "commit text"
8. если после коммита я исправил файл, то
git status
для всех файлов помеченных modified нужно сделать
git restore <имя файла>
таким образом файлы откатятся на состояние коммита
9.git push это мы заливаем все измененные файлы в свою ветку
_____________________________________________________________________________
Если надо скачать определенный комит, то пишем
git log
После этого копируем hash(страшное 16х число)
пишем git checkout <hash> (прешли к желаемому комиту)(все файлы сразу возвращаются на состояние коммита)
____________________________________________________________________________
git branch <branch name> - создает ветку и состояние ветки(файлов) из текущего коммита
git checkout <branch name> - переключиться на ветку
git checkout -b <branch name> - создать ветку и переключиться на нее
чтобы запушить в новую ветку 
git push --set-upstream origin <branch name>
_____________________________________________________________________________
чтобы ветку а в ветку в нужно:
перейти на ветку а и написать
git merge b
при появлении конфликтов заходим в файлы с окнфликтами и оставляем то, чно нужно
git status
git add <file name>
git commit -m "message" (после разрешения конфликта и этой комманды он сразу мержит)
