# Эмулятор UNIX-подобной командной оболочки

Практическая работа по созданию командной оболочки с виртуальной файловой системой. Эмулятор написан на Python и работает с файлами в памяти: он загружает дерево каталогов из ZIP-архива или из ZIP-архива, закодированного в Base64. Команды не изменяют файлы реальной операционной системы.

## Возможности

- Интерактивный REPL с настраиваемой строкой приглашения.
- Виртуальная файловая система в оперативной памяти, загружаемая из ZIP или Base64-кодированного ZIP.
- Поддержка абсолютных и относительных путей, `.` и `..`.
- Выполнение команд из стартового сценария перед переходом в интерактивный режим.
- Команды `ls`, `cd`, `cat`, `chown`, `history`, `vfs_load` и `exit`.
- Тесты парсера, конфигурации, команд, REPL и виртуальной файловой системы.

`chown` меняет владельца узла только внутри виртуальной файловой системы. Команда `vfs_load` загружает другой архив и заменяет текущую виртуальную файловую систему.

## Требования

- Python 3.11 или новее.
- Для запуска эмулятора сторонние Python-библиотеки не требуются. Для тестирования используется `pytest`.

## Установка и запуск

Перейдите в каталог проекта:

```sh
cd unix-shell-emulator
```

Посмотреть параметры запуска:

```sh
./run.sh --help
```

Запустить эмулятор с примером виртуальной файловой системы:

```sh
./run.sh --vfs vfs_samples/few_files.zip
```

Запустить сценарий команд, а затем перейти в REPL:

```sh
./run.sh --vfs vfs_samples/few_files.zip --script scripts/test_all.txt
```

То же действие выполняет скрипт операционной системы:

```sh
./os_scripts/run_with_script.sh
```

Запустить без архива — эмулятор откроется с пустой виртуальной файловой системой:

```sh
./run.sh
```

## Параметры командной строки

| Параметр | Назначение |
| --- | --- |
| `--vfs PATH` | ZIP-архив виртуальной файловой системы или файл с Base64-кодированным ZIP. |
| `--script PATH` | Файл команд, выполняемых перед интерактивным REPL. |
| `--prompt TEMPLATE` | Шаблон приглашения. Поддерживаются поля `{user}`, `{host}` и `{cwd}`. |

## Встроенные команды

| Команда | Назначение |
| --- | --- |
| `ls [PATH]` | Показать содержимое каталога; без пути используется текущий каталог. |
| `cd [PATH]` | Перейти в каталог; без аргумента перейти в корень VFS. |
| `cat PATH...` | Вывести текстовое содержимое одного или нескольких файлов. |
| `chown OWNER PATH` | Изменить владельца файла или каталога в VFS. |
| `history` | Показать команды, введённые в текущем сеансе. |
| `vfs_load ARCHIVE` | Загрузить архив и заменить текущую VFS. |
| `exit` | Завершить работу эмулятора. |

## Стартовые сценарии

В сценарии указывается по одной команде на строку. Пустые строки и строки, начинающиеся с `#`, игнорируются. Результаты команд выводятся до начала интерактивного ввода.

- `scripts/startup.txt` — основной стартовый сценарий.
- `scripts/test_all.txt` — пример последовательной проверки команд.
- `scripts/test_errors.txt` — сценарий для проверки обработки ошибок.

## Тестирование

Установить проект вместе с зависимостью для тестов и запустить весь набор:

```sh
python3 -m pip install -e '.[test]'
make test
```
