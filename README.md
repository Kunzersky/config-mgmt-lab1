# Эмулятор UNIX-подобной командной оболочки

Практическая работа по созданию командной оболочки с виртуальной файловой
системой. Эмулятор написан на Python и работает с файлами в памяти. Образы VFS
хранятся в репозитории как текстовые Base64-файлы; реальные файлы операционной
системы команды не изменяют.

## Этапы варианта 12

1. **REPL и команды-заглушки.** Создан цикл чтения команд, приглашение и обработка
    неизвестных команд.
2. **Параметры запуска и сценарии.** Поддерживаются `--vfs`, `--script` и
    `--prompt`; при старте выводятся все параметры. Команды стартового сценария
    отображаются вместе с приглашением, имитируя ввод пользователя.
3. **Виртуальная файловая система.** ZIP-образ загружается из `.b64` в память;
    примеры включают минимальную VFS, набор файлов и дерево `a/b/c/deep.txt`.
4. **Парсер и базовые команды.** Добавлены разбор аргументов и команды `ls`,
    `cd`, `cat`, `history` и `exit`.
5. **Дополнительные команды и проверка.** Добавлены `chown`, `vfs-load`,
    `conf-dump`, отображение владельцев в `ls -l` и сценарии этапов.

## Установка и запуск

Требуется Python 3.11 или новее. Запуск не требует сторонних библиотек.

```sh
./run.sh --help
./run.sh --vfs vfs_samples/few_files.b64
./run.sh --vfs vfs_samples/few_files.b64 --script scripts/test_all.txt
```

Три примера запуска для вариантов VFS:

```sh
./os_scripts/run_minimal.sh
./os_scripts/run_few_files.sh
./os_scripts/run_deep.sh
```

Полный сценарий запускается командой `./os_scripts/run_with_script.sh`.
Без `--vfs` создаётся пустая VFS.

Сценарии этапов запускаются из корня проекта:

```sh
./run.sh --vfs vfs_samples/deep_tree.b64 --script scripts/stage3.txt
./run.sh --vfs vfs_samples/few_files.b64 --script scripts/stage4.txt
./run.sh --vfs vfs_samples/few_files.b64 --script scripts/stage5.txt
```

## Параметры запуска

| Параметр | Назначение |
| --- | --- |
| `--vfs PATH` | Путь к ZIP-архиву или его Base64-кодированному содержимому. |
| `--script PATH` | Стартовый файл команд, выполняемый до интерактивного режима. |
| `--prompt TEMPLATE` | Шаблон приглашения с полями `{user}`, `{host}` и `{cwd}`. |

При запуске печатаются значения всех трёх параметров. Команда `conf-dump`
повторно выводит те же значения внутри REPL.

## Встроенные команды

| Команда | Назначение |
| --- | --- |
| `ls [-l] [PATH ...]` | Показать содержимое каталогов или указанные файлы; `-l` добавляет владельца. |
| `cd [PATH]` | Перейти в каталог; без аргумента перейти в корень VFS. |
| `cat PATH...` | Вывести текстовое содержимое файлов. |
| `chown OWNER PATH` | Изменить владельца узла внутри VFS. |
| `history` | Показать команды текущего сеанса. |
| `vfs-load ARCHIVE` | Загрузить другой ZIP или Base64 ZIP и заменить текущую VFS. |
| `conf-dump` | Показать параметры запуска. |
| `exit` | Завершить работу эмулятора. |

## Стартовые сценарии

В файле указывается одна команда на строку. Пустые строки и комментарии
игнорируются. Перед выполнением команда печатается с текущим приглашением.
После первой ошибки сценарий прекращается, и эмулятор завершает работу без
перехода в интерактивный режим.

- `scripts/startup.txt` — начальная проверка REPL.
- `scripts/test_all.txt` — успешная проверка всех встроенных команд.
- `scripts/stage3.txt`, `scripts/stage4.txt` и `scripts/stage5.txt` — сценарии
    соответствующих этапов; проверка ошибки расположена последней в сценариях
    этапов 4 и 5.
- `scripts/test_errors.txt`, `scripts/test_error_cd.txt`,
  `scripts/test_error_cat.txt` и `scripts/test_error_chown.txt` — отдельные
  сценарии ошибок, каждый останавливается на своей первой ошибке.

## Структура проекта

```text

├── Makefile                   # запуск, тесты и очистка
├── pyproject.toml             # настройки Python-пакета и pytest
├── run.sh / run.bat           # запуск в Unix-подобной ОС / Windows
├── os_scripts/                # запуск с каждой VFS и тестовым сценарием
├── scripts/                   # сценарии этапов и тестирования
├── src/
│   ├── config.py              # параметры командной строки
│   ├── main.py                # печать конфигурации и запуск
│   ├── parser.py              # разбор введённых команд
│   ├── repl.py                # REPL и выполнение стартовых сценариев
│   ├── commands/              # встроенные команды
│   └── vfs/                   # узлы, операции и загрузчик VFS
├── tests/                     # автоматические тесты
└── vfs_samples/               # Base64-образы виртуальных файловых систем
```
